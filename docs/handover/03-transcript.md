## Earlier standing instructions (steps 1 and 2)

- Docker-only development, everything in English in the repository, commit
  at each significant step, push only at validation milestones after the
  owner's OK, document in code + README + wiki + changelog.
- Validation reports end with a numbered **« Recette »** checklist.
- Repository public (GitHub wiki on the free plan), `master` = README only,
  `dev` = work.
